# 六爻断卦方法论（自研 · 公版依据）

> 本文件供 AI 在拿到 `scripts/liuyao.py` 的排盘结果后，按固定顺序解读使用。
> 依据《增删卜易》《卜筮正宗》等公版经典整理。先定用神，再看旺衰，后看动静生克，最后综合趋势化断语。**每条结论必须标注依据**（出自哪一爻的六亲/六神/生克）。
> 配套参考：基础理论体系（阴阳/八卦/五行/六亲/用神/动静/进退/月日/暗动/化废/伏反吟）见 `references/liuyao_basis.md`；刑合会象义字典见 `references/liuyao_xinghui.md`。

## 一、取用神（断卦第一步，先问清所问之事）

用神 = 代表「所问之事」的那一爻六亲。取错用神，全盘皆错。

| 所问之事 | 用神（六亲） |
|----------|--------------|
| 财运、买卖、经营、物品、妻室（男问妻） | 妻财 |
| 工作、官职、功名、考试、官司、疾病、小人 | 官鬼 |
| 长辈、父母、文书、契约、房屋、车船、学历 | 父母 |
| 子女、晚辈、下属、医药、解忧、享乐、宠物 | 子孙 |
| 兄弟、朋友、同事、同伴、竞争者、分财 | 兄弟 |
| 自身整体状态、我方意愿 | 世爻 |
| 对方、外部环境、事体本身 | 应爻 |

> **六亲基准（重要）**：六亲的「我」一律以**本卦所在卦宫的五行**为准。本卦与变卦的六亲都用这同一套基准计算，**变卦不另起宫**（即不能拿变卦自己的卦宫五行去重算它的六亲）。脚本 `liuyao.py` 已按此规则输出，解读时直接用即可，勿把变卦当独立宫重排六亲。

注意：
- 一事可能多用神。如问「合伙生意」：妻财（财）+ 兄弟（合伙人）+ 官鬼（执照/合同）同看。
- 问感情：男问妻室取妻财，女问夫君取官鬼；问关系发展兼看世应。
- 用神不现（卦中无此六亲）：看伏神（本宫该六亲伏于何爻之下），或借他爻权代。初学者先以世应+明显六亲断，不强行取伏。

## 二、用神旺衰（断卦核心）

旺衰看「月建 + 日辰 + 空亡/月破 + 得位」四重。

### 2.1 月建（司一个月之权，力量最大）
月建地支五行：寅卯木、巳午火、申酉金、亥子水、辰戌丑未土。

用神与月建关系（旺 → 衰）：
- **旺**：用神五行 == 月建五行（如用神属木，月在寅卯）。
- **相**：月建生用神（如用神木，月在亥子水生木）。次旺，可用。
- **休**：用神克月建（如用神木，月在辰戌丑未土，木克土）。有气但减分。
- **囚**：月建克用神（如用神木，月在申酉金克木）。衰。
- **死（废）**：用神生月建（如用神木，月在巳午火，木生火）。泄气，最无力之一。

### 2.2 日辰（司一日之令，能生克制化一切爻）
- 日辰生用神、或日辰与用神比和（同五行）→ 用神增力，纵月衰亦不完全无用。
- 日辰克用神 → 减力（但日克不如月克重，且日辰可冲起静爻为暗动）。
- 日辰冲静爻 → **暗动**（静爻被日辰冲，相当于动，有生克力）；日辰冲动爻 → 散（动爻被日冲，力量涣散，凶事可散、吉事亦散）。
- 日辰冲空亡爻 → **冲空则实**（短期有用）；日辰合住用神 → 待冲开。

### 2.3 空亡（旬空）
- 脚本已算好 `空亡` 地支，落在该地支的爻为「空」，**虚空无力**。
- 空亡爻：吉事落空、凶事亦空（凶事空反为减轻）。
- 出空方有用：① 到该地支当值的日子（填实）；② 被日辰冲（冲空则实）；③ 动爻化出填实。
- **真空**：月破 + 空亡同临 → 彻底无用，事主不成。
- **空亡的象不止「落空」**：空亡爻出空/填实，也常应「契约终止、关系了结」（如招聘语境下父母空亡出空 → 员工离职/走人），并非只有「招不到/虚」一面；须结合卦象（如师卦主统率/整顿）综合判断，勿一见空亡只断「不成」。

### 2.4 月破
- 脚本已标 `月破`（爻地支被月建所冲，如月建子则午爻月破）。
- 月破爻：当月无用，逢生亦散；出月（过本月）或可转，或待合破、填实。**月破之爻为忌最凶，为用则事难成**。

### 2.5 得位 / 强弱小结
- 用神旺（月旺或日旺）且无空破 → 事易成、吉。
- 用神衰又空破 → 事难成、凶。
- 旺衰临界时，回到「月建+日辰」综合判断，不单看一项。

### 2.6 用神受克的常见象
- 用神被月建/日辰克（尤其「月克/日克」）→ 该用神所代表的人/事**受损、流失、不顺**，不单是「减力」。
- 例：用神**子孙（员工/下属）逢火克金（如午月火旺克金）→ 员工流失/离职**；用神妻财逢克 → 财损；用神官鬼逢克 → 职位/权威受损。
- 用神受克 + 空亡/月破 → 该人/事更易落空或终结。

> 日月旺衰的量化读法（临日辰+2、日辰生合+2、克合-1 等评分）见 `references/liuyao_basis.md` §八。

## 三、动静与生克（断卦变数）

- **静爻**：只受生克，不主动作用。
- **动爻**：有变爻，主动生克他爻，是事态变化的枢纽。「有动则有变」。
- **动爻变出之爻（变爻）**：遵循「归墟 / 云派」默认方法——变爻可作用于本位动爻（回头生/回头克本爻）；**变卦中的静爻不参与作用**；**本卦静爻一般不参与作用**；当变爻与动爻无作用时，变爻才可作用于本卦的爻（据云派六爻傅师兄）。
  - 回头生：动爻化出之爻生本爻 → 吉上加吉。
  - 回头克：动爻化出之爻克本爻 → 吉转凶、事有反复或自身受制。
- **进神 / 退神**（动爻变出同五行相邻地支）：
  - 进神（趋于旺盛）：水 亥→子、木 寅→卯、火 巳→午、金 申→酉；土按 辰→未→戌→丑 顺行。主吉事速成、凶事加剧。
  - 退神（趋于消退）：反之（子→亥、卯→寅、午→巳、酉→申；土 丑→辰 逆行）。主事渐消、渐退、延误。
- **反吟**：动爻变出冲克本位之爻（如子化午），或卦变冲（内外卦相冲）。主反复不定、事多波折、去而复返。
- **伏吟**：卦变比和（内外卦相同，如乾变乾），动爻不动之象。主忧郁呻吟、事迟滞难进。

> 动爻化废（化回头克/化退/化破/化绝）、进退神、伏吟反吟的细读与卦例见 `references/liuyao_basis.md` §六/七/十/十二。

### 3.1 刑冲合害规则（解读铁律，务必遵守）
- **本卦静爻一般不参与刑冲合害**：爻与爻之间的刑/冲/合/害，通常以动爻、变爻、世应以及日辰、月建为作用方；本卦静爻多不作为作用主体参与（例外：动爻合住本卦静爻「合起」仍有效）。注：日辰冲静爻为「暗动」、月建冲爻为「月破」，属日月对爻之作用，不在此限。
- **刑不看吉凶，只看象**：六爻中「刑」仅用于取意象（如子卯刑=无礼纠缠、寅巳申=无恩），不据以判吉凶；吉凶仍看旺衰与生克。三刑／六合／三合／三会的详细象义字典见 `references/liuyao_xinghui.md`。
- **冲、合最常用**：断卦时冲与合是主力工具——冲主散／动／激发／破裂，合主聚／绊／成局／羁留，优先使用。
- **害很少用**：相害（六害）实战极少采用，一般可忽略；除非明显成象，不主动取害断吉凶。

### 3.2 本卦→变卦 的卦象组合意象
- 除用神旺衰外，本卦与变卦的「卦名意象流转」也要看：本卦之象 → 变卦之象，常揭示事件的性质与走向（不止单面）。
- 例：**比 → 师**。比=亲和、择人而附、建队伍；师=统率、整顿、带兵。比之师，是从「组建队伍」走向「统率/整顿队伍」——**聘用与辞退皆属「统率」**，故招员工得此象，既可能招到、也可能裁人，是队伍的整体流转，切勿只取「招到」一面。
- 其它常见：泰→否（通泰转闭塞）、既济→未济（事将成转未竟）、升→夬（积小成转决断）等，均须结合用神综合看，卦象只定「调性」不单独定吉凶。
- 参考案例：`records/case_水地比变地水师_招员工_验证.json`（hire+fire 全程应验）。

## 四、世应关系（看我方与对方/环境）

- **世爻** = 求测者自己；**应爻** = 所问之事的对方或外部环境。
- 世应五行关系（脚本已给出世应五行，可自判）：
  - 世应相生 → 合作顺、彼此助益。
  - 世应比和 → 均势，需看用神。
  - 世克应 → 我能掌控局面、主动。
  - 应克世 → 外部压制、被动、费力。
- 合作/感情/交易类问题，世应关系尤为重要。

## 五、六神修饰（辅助信息，不能喧宾夺主）

六神由占卦日干决定（脚本已装好），**先看用神旺衰，再看六神修饰**，六神不单独定吉凶。

| 六神 | 性质 | 常见象义 |
|------|------|----------|
| 青龙 | 吉 | 喜事、文书、酒色、顺畅 |
| 朱雀 | 中偏吵 | 口舌、文书、信息、是非 |
| 勾陈 | 迟滞 | 田土、羁留、勾连、缓慢 |
| 螣蛇 | 虚惊 | 怪异、缠绕、虚惊、多变 |
| 白虎 | 凶 | 血光、伤灾、刑伤、果断 |
| 玄武 | 暗昧 | 盗贼、暗昧、隐私、暧昧 |

用法：如用神本旺，临青龙 → 吉上加喜；用神本衰，临白虎 → 凶上加凶；空亡爻临玄武 → 虚而不实、防欺瞒。

## 六、综合断语与应期

### 6.1 断语顺序（严格遵守）
1. 定用神（第一节）。
2. 断用神旺衰（第二节：月建、日辰、空亡、月破、得位）。
3. 看动爻与变爻（第三节：回头生克、进退、反吟伏吟）。
4. 看世应（第四节）。
5. 六神修饰（第五节）。
6. 综合：**趋势化**表述（易/倾向/利于/需注意/待冲实），不铁口直断。

### 6.2 应期（何时发生）思路
- 用神旺静 → 应期在「用神当值之日/月」或「被合之日」。
- 动爻 → 逢值（该地支日）、逢合（被合日）为应。
- 空亡 → 出空填实、或被冲空之日。
- 月破 → 出月、合破、填实之日。
- 合住 → 冲开之日。
- 应期只给「倾向区间」，不下精确日期铁断。

### 6.3 诚实边界（必守）
- 六爻是文化传统与概率性倾向分析，**不预言命运、健康、投资、职业结局**。
- 不承诺改运、消灾、转运，不提供任何「法术」建议。
- 凡真实人生决策，以现实为准、结合专业意见。
- 空亡/月破/衰爻 ≠ 绝对凶；旺相 ≠ 绝对吉。趋势表述，留有余地。
