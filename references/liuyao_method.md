# 六爻断卦方法论（自研 · 公版依据）

> 本文件供 AI 在拿到 `scripts/liuyao.py` 的排盘结果后，按固定顺序解读使用。
> 依据《增删卜易》《卜筮正宗》等公版经典整理。先定用神，再看旺衰，后看动静生克，最后综合趋势化断语。**每条结论必须标注依据**（出自哪一爻的六亲/六神/生克）。

---

## 一、取用神（断卦第一步，先问清所问之事）

用神 = 代表「所问之事」的那一爻六亲。取错用神，全盘皆错。

| 所问之事 | 用神（六亲） |
|----------|--------------|
| 财运、买卖、经营、物品、妻室（男问妻） | 妻财 |
| 工作、官职、功名、考试、官司、疾病、小人 | 官鬼 |
| 长辈、父母、文书、契约、房屋、车船、学历 | 父母 |
| 子女、晚辈、下属、医药、解忧、享乐、宠物 | 子孙 |
| 兄弟、朋友、同事、同伴、竞争者、分财 | 兄弟 |
| 自身整体状态、我方意愿 | 世爻 |
| 对方、外部环境、事体本身 | 应爻 |

注意：
- 一事可能多用神。如问「合伙生意」：妻财（财）+ 兄弟（合伙人）+ 官鬼（执照/合同）同看。
- 问感情：男问妻室取妻财，女问夫君取官鬼；问关系发展兼看世应。
- 用神不现（卦中无此六亲）：看伏神（本宫该六亲伏于何爻之下），或借他爻权代。初学者先以世应+明显六亲断，不强行取伏。

## 二、用神旺衰（断卦核心）

旺衰看「月建 + 日辰 + 空亡/月破 + 得位」四重。

### 2.1 月建（司一个月之权，力量最大）
月建地支五行：寅卯木、巳午火、申酉金、亥子水、辰戌丑未土。

用神与月建关系（旺 → 衰）：
- **旺**：用神五行 == 月建五行（如用神属木，月在寅卯）。
- **相**：月建生用神（如用神木，月在亥子水生木）。次旺，可用。
- **休**：用神克月建（如用神木，月在辰戌丑未土，木克土）。有气但减分。
- **囚**：月建克用神（如用神木，月在申酉金克木）。衰。
- **死（废）**：用神生月建（如用神木，月在巳午火，木生火）。泄气，最无力之一。

### 2.2 日辰（司一日之令，能生克制化一切爻）
- 日辰生用神、或日辰与用神比和（同五行）→ 用神增力，纵月衰亦不完全无用。
- 日辰克用神 → 减力（但日克不如月克重，且日辰可冲起静爻为暗动）。
- 日辰冲静爻 → **暗动**（静爻被日辰冲，相当于动，有生克力）；日辰冲动爻 → 散（动爻被日冲，力量涣散，凶事可散、吉事亦散）。
- 日辰冲空亡爻 → **冲空则实**（短期有用）；日辰合住用神 → 待冲开。

### 2.3 空亡（旬空）
- 脚本已算好 `空亡` 地支，落在该地支的爻为「空」，**虚空无力**。
- 空亡爻：吉事落空、凶事亦空（凶事空反为减轻）。
- 出空方有用：① 到该地支当值的日子（填实）；② 被日辰冲（冲空则实）；③ 动爻化出填实。
- **真空**：月破 + 空亡同临 → 彻底无用，事主不成。

### 2.4 月破
- 脚本已标 `月破`（爻地支被月建所冲，如月建子则午爻月破）。
- 月破爻：当月无用，逢生亦散；出月（过本月）或可转，或待合破、填实。**月破之爻为忌最凶，为用则事难成**。

### 2.5 得位 / 强弱小结
- 用神旺（月旺或日旺）且无空破 → 事易成、吉。
- 用神衰又空破 → 事难成、凶。
- 旺衰临界时，回到「月建+日辰」综合判断，不单看一项。

## 三、动静与生克（断卦变数）

- **静爻**：只受生克，不主动作用。
- **动爻**：有变爻，主动生克他爻，是事态变化的枢纽。「有动则有变」。
- **动爻变出之爻（变爻）**：只与本位动爻发生生克，不直接克他爻（变爻回头生/回头克本爻）。
  - 回头生：动爻化出之爻生本爻 → 吉上加吉。
  - 回头克：动爻化出之爻克本爻 → 吉转凶、事有反复或自身受制。
- **进神 / 退神**（动爻变出同五行相邻地支）：
  - 进神（趋于旺盛）：水 亥→子、木 寅→卯、火 巳→午、金 申→酉；土按 辰→未→戌→丑 顺行。主吉事速成、凶事加剧。
  - 退神（趋于消退）：反之（子→亥、卯→寅、午→巳、酉→申；土 丑→辰 逆行）。主事渐消、渐退、延误。
- **反吟**：动爻变出冲克本位之爻（如子化午），或卦变冲（内外卦相冲）。主反复不定、事多波折、去而复返。
- **伏吟**：卦变比和（内外卦相同，如乾变乾），动爻不动之象。主忧郁呻吟、事迟滞难进。

## 四、世应关系（看我方与对方/环境）

- **世爻** = 求测者自己；**应爻** = 所问之事的对方或外部环境。
- 世应五行关系（脚本已给出世应五行，可自判）：
  - 世应相生 → 合作顺、彼此助益。
  - 世应比和 → 均势，需看用神。
  - 世克应 → 我能掌控局面、主动。
  - 应克世 → 外部压制、被动、费力。
- 合作/感情/交易类问题，世应关系尤为重要。

## 五、六神修饰（辅助信息，不能喧宾夺主）

六神由占卦日干决定（脚本已装好），**先看用神旺衰，再看六神修饰**，六神不单独定吉凶。

| 六神 | 性质 | 常见象义 |
|------|------|----------|
| 青龙 | 吉 | 喜事、文书、酒色、顺畅 |
| 朱雀 | 中偏吵 | 口舌、文书、信息、是非 |
| 勾陈 | 迟滞 | 田土、羁留、勾连、缓慢 |
| 螣蛇 | 虚惊 | 怪异、缠绕、虚惊、多变 |
| 白虎 | 凶 | 血光、伤灾、刑伤、果断 |
| 玄武 | 暗昧 | 盗贼、暗昧、隐私、暧昧 |

用法：如用神本旺，临青龙 → 吉上加喜；用神本衰，临白虎 → 凶上加凶；空亡爻临玄武 → 虚而不实、防欺瞒。

## 六、综合断语与应期

### 6.1 断语顺序（严格遵守）
1. 定用神（第一节）。
2. 断用神旺衰（第二节：月建、日辰、空亡、月破、得位）。
3. 看动爻与变爻（第三节：回头生克、进退、反吟伏吟）。
4. 看世应（第四节）。
5. 六神修饰（第五节）。
6. 综合：**趋势化**表述（易/倾向/利于/需注意/待冲实），不铁口直断。

### 6.2 应期（何时发生）思路
- 用神旺静 → 应期在「用神当值之日/月」或「被合之日」。
- 动爻 → 逢值（该地支日）、逢合（被合日）为应。
- 空亡 → 出空填实、或被冲空之日。
- 月破 → 出月、合破、填实之日。
- 合住 → 冲开之日。
- 应期只给「倾向区间」，不下精确日期铁断。

### 6.3 诚实边界（必守）
- 六爻是文化传统与概率性倾向分析，**不预言命运、健康、投资、职业结局**。
- 不承诺改运、消灾、转运，不提供任何「法术」建议。
- 凡真实人生决策，以现实为准、结合专业意见。
- 空亡/月破/衰爻 ≠ 绝对凶；旺相 ≠ 绝对吉。趋势表述，留有余地。
