## 一、阴阳
- **阳**：清、轻、气、虚。
- **阴**：浊、重、实。

## 二、八卦（取象底稿）
- **乾为天**：气所成，三个阳爻。
- **兑为泽**。
- **离为火**。
- **震为雷**：初爻阳气穿过两个阴爻（可看作乌云）。
- **巽为风**。
- **坎为水**。
- **艮为山**。
- **坤为地**：重的物质构成大地。

## 三、五行 · 天干 · 地支
### 3.1 五行（既指实际物质，也指抽象概念）
- **木**：木制品（树木草木、铅笔、家具）；季节=春天；颜色=绿色；方位=东方；五德=仁；五味=酸；中医=肝胆；人生=生长、扩张阶段；抽象=生机、成长。
- **火**：火焰；季节=夏天；光明、文明、科技、传播性/教育教学等；颜色=红色；方位=南方；五德=礼；社会现象=自然选择传播性内容（如小红书等）。
- **金**：季节=秋天；颜色=白色（清冷如霜白，非黄金黄）；收敛、凋零、杀伐感；兵器/武器/剪刀（修剪）；变革、改革、命；五德=义；方位=西方。
- **水**：季节=冬天；寒冷、流动；颜色=黑色（至阴极端为黑——所有色聚为黑/玄，不发散之光）；方位=北方；五德=智；蓝色亦强赋水属性（排盘多蓝标水）。
- **土**：四季之末（每季最后一个月属土，非仅夏末）、中央；承载、孕育、包容、转换、缓冲（调和季与季，坤厚德载物）；颜色=黄色/卡其/咖；五德=信。

### 3.2 地支
十二地支：子 丑 寅 卯 辰 巳 午 未 申 酉 戌 亥。

- **六合（六组，正确）**：子丑合、寅亥合、卯戌合、辰酉合、巳申合、午未合（其中多有生合）。
  ⚠ **易错提醒**：`辰戌`、`卯酉` 实为**六冲**，不是六合。不要写成「辰戌合 / 卯酉合」。
- **六冲（六组）**：子午冲、丑未冲、寅申冲、卯酉冲、辰戌冲、巳亥冲。

### 3.3 天干
口诀：**甲乙东方木，丙丁南方火，戊己中央土，庚辛西方金，壬癸北方水**。
（甲 乙 丙 丁 戊 己 庚 辛 壬 癸）

## 四、六亲（以「我」为基准）
基准：**生我者父母，我生者子孙，我克者妻财，克我者官鬼，比和者兄弟**。

### 4.1 父母（生我者）
天地（提供生存环境）、城池城墙（遮风避雨保护）、衣服（遮体给自信）、布匹绸缎、工具杂货（螺丝刀助你拧螺丝）、舟车交通工具（助你快速位移）、文书知识学识（先人经验给予，即「生」）。
- 要点：物体本身不固定为「生/克」，随具体事件而变（螺丝刀助你，亦可能伤你）；基本形态是「帮助我、给予我力量」。

### 4.2 子孙（我生者）
晚辈、宠物、六畜禽兽；忠臣良将（解决内忧外患）、医药（治病去鬼）、解忧之神；官鬼含「鬼」成分，子孙克官鬼=去麻烦，故为**福德之神 / 福神**。
- 占功名/工作则不吉：子孙克官鬼→伤名气职位（同卦不同事，须变通）。

### 4.3 妻财（我克 / 我驱使）
货财、珠宝、钱粮、财产、一切有价值之物；男生测姻缘以妻财代表妻子/缘分/女人。
- 现代偏差：古代妻妾可驱使，现代仅「拥有」难驱使，不能以古书死搬；「必仆下意」现代多不成立。

### 4.4 官鬼（克我者）
- 官=管（约束、管理、维系平衡）；鬼=不好信息/麻烦/伤害。
- 两层含义：中性偏利的「管理约束」，与伤害性的「鬼」。违法被管、犯法被限制关押——皆「克我者为官鬼」。

### 4.5 兄弟（比和者）
同类之人；见财夺（资源有限，他多你少，未必主动欺凌）；占财物为**劫财之神**、行商克害之神；可夺财、夺妻（抢女友）。
- 占感情/财物时，兄弟多主竞争、分财、夺妻之象。

## 五、用神章
- 男问妻/财 → 妻财为用；女问夫/姻缘 → 官鬼为用；**未见面相亲对象同理**（以妻财/官鬼衡量缘分）。
- 文书学业 → 父母为用；父母长辈健康 → 父母为用；孩子 → 子孙为用；考试/升迁/考公 → **父母 + 官鬼参看**（父母=成绩学识，官鬼=官方认定/名次）。
- 用神选择：初学先公式化锚定（见 `liuyao_method.md` §一表）；熟练后「看卦再定用神」——用神随卦象变化，非公式化。留引子：用神是推理起点，须结合事件与卦象。
- **世爻**：当下时空「我」的状态，或所测之事的状态（事在人为）。
- **应爻**：当下时空「他人 / 事物」的状态。
- **元神**：生用神者；**忌神**：克用神者（不好的信息表达）。
- **静爻**：不能作用于他爻；**变爻**：由动爻变化而来，只作用于本位动爻。

## 六、动静与动爻
- 动爻有生克权，可作用于本卦的动爻与静爻。
- 举例：忌神兄弟丑土发动克制妻财亥水。
- **回头生 / 回头克**：动爻化出之爻给予 / 克制本爻。
  - 用神化回头生 → 吉（钱越来越多、我越来越强）。
  - 元神化回头生 → 吉（力量源泉越来越好）。
  - 忌神化回头生 → **凶**（坏力量被放大，破财从 500 变 5 万）。
  - 关键：分清「谁」化回头生/回头克，**非一律吉**。
- **动动相连**：动爻优先作用于动爻。隔位相克（如金克木）时，中间加水（金生水→水生木）即转循环相生（「吸星大法」，把克我之力化为助我）。元神与忌神同时发动 → 忌神生元神再生用神，连续相生化解。

## 七、进退神
- **进神**：亥化子、寅化卯、巳化午、申化酉；土顺行 丑→辰→未→戌。主由此前进（春木之荣、有源之水，越来越好）。
- **退神**：反之（子化亥、卯化寅、午化巳、酉化申；土逆行 辰→丑）。主渐退（秋花凋零）。
- 用神化进好、元神化进好；**忌神化进凶**（阻力扩大），忌神化退好（坏信息消散，但须看当下旺衰——化进退较缓，当下旺仍有阻力）。
- **世爻化进**：自强自旺；若持忌神则反对情绪递增（如测工作，子孙持世化进=越来越讨厌工作）。**世爻化退**：放弃退缩消极（即便忌神持世化退仍不利）。
- 卦例细节：
  - 问丈夫回来——土为皮肤，木克土=划开皮肤、手术；木亦表锋利器械。
  - 眼睛肿胀——世爻未土，兄弟寅木化进（忌神化进），肿胀渐重但不致命，用药即好；五爻主面部；须符合实际。

## 八、月建 与 日辰（旺衰量化底稿）
### 8.1 月建
- 司一月之权，影响整月旺衰；寅卯木月、巳午火月「有气」。
- 以「旺相休囚死」判定季节性旺衰；月主「从前和当月」。

### 8.2 日辰
- 日辰（日建 / 日令）= 起卦当天干支，主当日；与月建平级同权，且「四时俱旺」（不受季节限），对长远影响可能更持久。
- 日辰无「气」一说、无「休囚」之说。
- **日辰对爻的量化评分**（仅作读法参考，脚本不算）：
  - 临日辰：+2
  - 日辰生合：+2
  - 日辰相扶：+1
  - 日辰相生：+1
  - 日辰平合：0
  - 日辰对爻无作用：0
  - 日辰克合：-1
  - 日辰相克：-1
  - 日辰冲爻：分**日破**（静爻无气被冲散）与**暗动**（静爻被冲起，见第九节）。
- 日月共同决定「起卦当时、未分析动变前」的原本状态。量化 >0（旺相）→ 可取积极形容词描绘（用神旺=人帅/有责任感/抗压；力量弱则描绘偏弱）。具体结合六亲 / 六神 / 地支 / 神煞综合塑造（同一人不同事状态会变）。
- 月主从前当月，日主当下未来。

## 九、暗动（日辰冲静爻成暗动的条件）
静爻被日辰冲，满足其一即为**暗动**（有生克力）：
1. 静爻有月建帮助，或静爻在月内有气；
2. 静爻得有力动爻相生；
3. 静爻旬空。
（反之为**日破**：静爻无气被日冲散，力量涣散。）

## 十、动爻化废（发动而力量趋于完结）
动爻发动后若遇下例，主「事情发生但最终停止 / 消散」：
- 发动化**回头克**；
- 发动化**退**；
- 发动化**破**（变爻月破）；
- 发动化**绝**（十二长生：长生→沐浴→冠带→临官→帝旺→衰→病→死→墓→绝→胎→养；特殊例：酉金化寅木、子水化巳火）。

## 十二、伏吟 · 反吟
- **伏吟**：卦变比和（内外卦相同，如乾变乾），动爻不动之象；主忧郁呻吟、事迟滞难进。
- **反吟**：动爻变出冲克本位之爻（如子化午），或卦变冲（内外卦相冲）；主反复不定、事多波折、去而复返。
