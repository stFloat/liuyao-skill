# 财运 / 求财专项读法（六爻占验 · 专项参考）

> 本文件为「财运类」占问的专项方法论，配合 `liuyao_method.md`（通用断法）与 `liuyao_basis.md`（基础理论体系）使用。
> 财运类以**妻财为用神**，吉凶以财为主要判断关键，但财与世爻的关联、子孙（财源）、兄弟（劫财）、父母（保障/本金）、官鬼（护航/规则）的配合决定成败。
> 本专项内容由用户提供之讲义整理，公版依据（《增删卜易》《卜筮正宗》等）一致。

---

## 1. 总论：财运的分类与用神

财运类是预测中常见的占验类目，主要目的为求财。可分为：时间范围内财运、投资财运、事业财运、生意财运等，其看法大多一致，**都是以财为用神**，吉凶方面以财为主要判断关键。

- **长期财**：一般做生意、投资、事业型财运多为长期财运，长期财运需额外关注**子孙爻**——子孙生妻财，子孙为财之元神，往往在生意中代表客户、产品、流量、资源等，是维系财产价值的重要信息。若子孙爻出现极不好之情况，则财星没有维持，会出现入不敷出、萧条冷寂等现象。
- **短期财**：短期求财，或一次性买卖（如介绍得好处费、某次订单、某一短期时间范围内），子孙爻的情况不会过多影响吉凶，**主要看财爻的信息即可**。

## 2. 财星、子孙与世爻的关联（核心格局）

财运卦中，财星和子孙爻的吉凶固然重要，但如果出现以下情况，代表财富与自身无缘，或钱财流失、利益被他人抢占：
- 财星与世爻**关联微弱**；
- 世爻**衰败无力担财**；
- 财星**转生应爻**（财向他方）。

### 吉利格局（财星向我靠拢）
- **财爻持世**
- **财来生世**
- **财来合世**

以上皆是财星向自己靠拢的吉象。若**子孙爻持世来生财**，代表自身具备资源、技术、客源等条件，可凭借自身能力创造财富。

### 忌讳格局
- **兄弟忌神持世**：兄弟持世大多主破财消耗，且让自己和财的缘分变浅，很难发大财，即便获利也守不住钱财。因兄弟克制财星，带有竞争争夺、内卷博弈、赌斗较量之意；求财多是在既定收益里划分份额，所得十分有限。
- **父母爻持世（辛苦劳碌）**：父母会被财星克制；倘若财爻发动克制世爻，也有得财机会，但前提是世爻旺相可承受克制。这种财运往往需辛苦打拼、费心经营才能获利，易被钱财牵绊束缚；又因世爻遭财克制，不利于长期发展，潜藏积劳成疾、因财招祸隐患。
- **财星与世爻相冲 / 发动冲克世爻**：大多为不吉之象，就算世爻旺相，财运也难以长久；只适合求短期快钱，特点是钱财来得快、去得也快，很难积蓄留存。

## 3. 兄弟（劫财之神，忌神）

- 兄弟为忌神、为劫财之神，一般以**兄弟发动**为不好的信息。
- 兄弟在财运卦中**不能代表合作伙伴**（财运卦以财为用神，其余六亲围绕财爻转变分析；分析合作伙伴一般以**应爻**代替，见合作卦专项）。
- 兄弟本意是**花钱**；财运为得财，故花钱与财背道而驰。但**并非所有花钱都不好**：投资要花钱、打广告要花钱。若兄弟发动可生子孙，而子孙又能化妻财，说明钱花对了地方——花钱可增加销量或提升利润，使生意流转。
- 兄弟也可代表**竞争对手**（与自己五行相同的其他爻也可表竞争对手）。财运中部分求财方式免不了遭遇竞争（或明或暗），故兄弟旺象也用来表达行业竞争激烈、利润微薄，需更多投资与消耗才能获取利益。

---

## 4. 父母（保障 / 场地 / 本金）

- 父母表达很多样，往往不固定。在有店铺、门面等情况下，父母可表达求财的**场地、商场、店铺、门面**等信息。
- 父母是**生我者**（我为此卦，父母是对卦的保障），即对求财之事的保障，可取象为：品牌、文化、公司、法务、合同、条款等——一切保障求财顺利、增加背书、提升形象的事物。
- 父母会**克制子孙**（子孙为利，是对利益的压榨），故父母多问**本金**——为店铺、形象、法务等保障所支出的费用，无疑压缩收益。故**父母发动往往有本大利薄之意**，多重启动、需本钱的求财方式（风险越大收益越大，父母越大风险越小故收益变小）。
- 父母发动克子孙，可延伸取象为**讨价还价**（我想压榨你的利润，故产生价钱商量）——财运卦中少见，买卖卦中常遇。

---

## 5. 官鬼（护航 / 规则 / 官方）

- 官鬼所表达的象义丰富，具体卦象具体定义。官鬼为**克我**者（我为卦），一切约束此事者皆可为官鬼，可取：管理、工商、规则、法律；亦可为困难、麻烦、问题等。
- 官鬼可**制兄弟**（兄弟为劫财之神），故财运卦中官鬼也扮演好角色，为生意**保驾护航**。官鬼是官方认证，如证书、品牌、专利、名声、名气等；官鬼让竞争对手无法发挥作用（不能仿冒品牌，或名声更大使其无法抢占市场）。
- 故财运卦中官的作用很大——「贵气」很重要，若得官方指定与认可，生意往往**垄断式、独享式**，多稳赚不赔。
- 官鬼为克我者，是对当下事的限制与管控，是对未来方向的把握，为**掌舵者**，往往对应计划、谋略、战略、方向等。

## 附：本专项在断卦中的取用要点（速查）

| 六亲 | 财运卦中角色 | 吉凶倾向 |
|------|--------------|----------|
| 妻财（用神） | 财本身 | 旺、持世、生世、合世为吉 |
| 子孙（元神） | 财源（客户/产品/流量） | 长期财须旺；受父母克则利薄 |
| 兄弟（忌神） | 劫财、花钱、竞争对手 | 静/破为利；发动多不吉（除非生子孙流转） |
| 父母 | 保障/场地/本金/合同 | 发动主本大利薄、辛苦 |
| 官鬼 | 规则/官方/护航 | 制兄弟为吉；过旺则管控重 |
| 世爻 | 我 | 旺相能担财；财生世/合世吉；财冲克世不吉 |
| 应爻 | 对方/合作伙伴 | 财转生应＝财向他方（不利） |
